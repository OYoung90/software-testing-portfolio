# 🧪 Software Testing Sandboxes

A collection of publicly available applications and environments I use to develop practical software testing and QA skills.

## Manual Testing

### [SauceDemo](https://www.saucedemo.com/)

E-commerce application used for functional testing, test design, test execution and defect reporting.

### [The Internet](https://the-internet.herokuapp.com/)

A collection of small web-testing scenarios covering authentication, forms, checkboxes, dynamic content, file uploads, alerts and other common web behaviours.

### [DemoQA](https://demoqa.com/)

Web application containing forms, buttons, widgets, tables and other UI components for testing practice.

### [Automation in Testing – Book Room](https://automationintesting.online/)

A more realistic web application for practising functional, exploratory, accessibility and later automation testing.

## API Testing

### [Restful-Booker](https://restful-booker.herokuapp.com/)

REST API testing environment for practising CRUD operations, authentication, request/response validation and negative testing.

## Test Automation

### [QA Practice](https://www.qapractice.com/)

Purpose-built practice sites for login, forms, e-commerce and flight booking, with examples for Selenium, Cypress and Playwright.

## How I use these environments

These sandboxes provide environments for developing practical testing skills without using confidential or production systems.

Projects in this portfolio will document the testing activities I carry out, including:

- Test planning
- Test scenario design
- Test case design
- Test execution
- Defect identification and reporting
- Exploratory testing
- API testing
- SQL/database testing
- Test automation
